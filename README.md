# 낚싯대 물리 액션 횡스크롤 데모

Unity 6.3(`6000.3.11f1`) 기준의 짧은 전투 데모입니다. 외부 아트 없이 기본 도형과 Line Renderer만 사용하며, `전투 → 낚시 → 강화된 전투`의 한 스테이지를 플레이할 수 있습니다.

## 실행

1. Unity Hub에서 이 폴더를 프로젝트로 엽니다.
2. `Assets/Scenes/FishingPrototype` 씬을 엽니다.
3. Play를 누릅니다.

## 조작

- `A / D`: 이동
- `W`: 점프
- `Space`: 게임 시작부터 플랫폼 위 어디서든 낚시 시작/타이밍 입력
- `마우스`: 낚싯대 조준 및 걸린 대상의 휘두를 방향 지정
- `좌클릭 짧게`: 곡선 궤적으로 채찍질. 적중해도 피해와 넉백만 발생
- `좌클릭 홀드`: 채찍이 적/작은 투척용 바위에 닿는 순간 포획. 버튼을 놓으면 현재 속도로 투척
- `우클릭 홀드`: 걸린 대상 당기기
- `R`: 전체 테스트 리셋

무거운 오브젝트를 낚은 뒤에는 바닥을 향해 `좌클릭 홀드`하면 추를 바닥에 꽂습니다. 버튼을 유지하는 동안 플레이어가 추를 중심으로 가속하며 원운동하고, 좌클릭을 놓으면 현재 속도로 날아갑니다. 마우스의 좌우 방향으로 이동 방향을 정할 수 있습니다.

## 스테이지 흐름

1. 게임 시작 직후부터 플랫폼 위 어느 위치에서든 `Space`를 눌러 낚시할 수 있습니다. 플랫폼 아래 전체가 바다입니다.
2. 빈 줄과 낚은 대상의 차이를 비교하려면 먼저 오른쪽의 첫 전투를 빈 줄로 진행한 뒤 낚시해도 됩니다.
3. 왕복하는 표시가 중앙 구간에 들어왔을 때 `Space`를 한 번 누릅니다.
4. 넓은 성공 구간에 맞히면 물고기, 정확한 중앙에 맞히면 무거운 오브젝트를 얻습니다.
5. 낚은 대상이 줄 끝에 붙은 상태로 두 번째 전투를 진행합니다.

낚시는 바닥에 서 있고 채찍질이나 포획 동작 중이 아닐 때만 시작할 수 있습니다. 낚시 도중 공격을 받아 공중으로 밀려나면 낚시가 취소되며, 새로 낚은 대상은 기존 줄 끝의 대상을 교체합니다.

## 확인할 것

- 빈 줄은 느린 준비 동작 뒤 줄 끝이 빠르게 따라오는 곡선 채찍 운동을 합니다.
- 짧은 클릭은 타격만 하고, 버튼을 누른 채 맞혔을 때만 대상을 겁니다.
- 밝게 표시되는 줄의 마지막 40%가 공격 범위이며, 줄 끝에 가까울수록 피해와 넉백이 강합니다.
- 포획은 마지막 10~15%가 닿았을 때만 가능하므로 일반 타격보다 정밀한 조준이 필요합니다.
- 걸린 대상을 바닥이나 다른 적에 빠르게 충돌시키면 대상과 충돌한 적에 추가 피해가 들어갑니다.
- 물고기는 빈 줄보다 조금 느리지만 피해와 넉백이 증가하고 포획도 유지됩니다.
- 무거운 오브젝트는 크게 느려지는 대신 가장 강한 피해와 넉백을 주며, 바닥 앵커 이동을 사용할 수 있습니다.
- 적은 빠른 근접형 러셔와 느리지만 강한 브루저 두 종류입니다.
- 플레이어가 쓰러지면 현재 구간의 체크포인트에서 복귀합니다.

핵심 수치는 `FishingRodController.cs` 상단의 Tuning 항목과 `HookableBody.cs`의 충돌 피해 계산부에서 빠르게 조절할 수 있습니다.
