# 스프린트 01 — 협업 규칙 적용

기간: 2026-10-30 ~ 2026-11-05 (1주 초안).
목표: 기존 전투를 유지하면서 협업 규칙을 적용하고 다른 담당자가 텍스트와 코드를 찾을 수 있게 한다.
담당자·리뷰어와 실제 일정은 팀에서 배정한다. 이 문서는 완료된 스프린트 이력이 아니다.

| 작업 | 상태 | 완료 기준 |
| --- | --- | --- |
| feature 브랜치 및 Git 연결 | 로컬 완료 | 원격 기존 이력을 유지하고 feature/team-conventions에서 작업 |
| 필드명·오브젝트 이름 정리 | 구현 완료 | camelCase, 직렬화 이전 이름 보존, 표시 이름 분리 |
| 표시 텍스트 CSV | 구현 완료 | 키 조회, 번역 대체, 잘못된 CSV 검증 |
| 문서·PR 템플릿·로컬 훅 | 구현 완료 | 커밋 헤더 및 보호 브랜치 푸시 검사 |
| 자동 검사 | 통과 | 전투·CSV·훅 검사 통과 |
| 실제 전투 플레이 | 미완료 | 공격·포획·투척·보정·독가스·저장 확인 |
| 원격 develop 초기 생성·보호 규칙 | 관리자 작업 필요 | PR 필수·승인 1명·직접 푸시 차단 |
| PR 리뷰·병합 | 미진행 | 최소 1명 승인 후 develop에 PR 병합 |

범위 제외: 기존 전투 씬/프리팹의 밸런스 SO 전환, 기본 PoC 수정, Linebreaker 수정, 새 전투 규칙.

검증 기록: 전투·CSV 회귀 검사, 로컬 훅 차단 검사, 씬 초기화 검사 통과. 기본 PoC/Linebreaker/전투 씬 원본 해시 유지. 검증용 Unity의 검색 인덱스 내부 예외 1건은 게임 코드 밖에서 발생했으며 플레이 초기화 검사는 통과했다. 실제 UI 배치·조작감 검증은 미완료.

후속 작업(2026-10-31): 플레이어·낚싯대 프리팹 전환 및 씬 배치 완료. 전투 회귀·프리팹 참조·에디터 수정값 유지·Play 모드 공격 시작 검사 통과. 적·맵·HUD의 에디터 전환은 다음 단계.

전체 전환(2026-10-31): 적·수리검·독·병·돌·맵·문·위치 마커·카메라·진행 시스템·Canvas HUD·줄/찌/조준선·효과음을 프리팹/에셋으로 이관. RuntimeInitialize/OnGUI/게임 실행 중 컴포넌트 조립 제거. 전투 중 생성은 프리팹 Instantiate만 사용. 기존 팀 리뷰·원격 병합 상태는 변경하지 않음.

- 전체 프리팹 전환 최종 검증: 별도 Unity 6000.3.11f1 검증 프로젝트에서 전투 회귀·프리팹 검사, 실제 Play(적 출현·수리검·병 소모와 보라색 독 피해·플레이어 중독), Windows64 빌드 통과. 씬/프리팹 에셋 GUID 누락 없음. 검증 에디터의 SearchDatabase 인덱스 예외 1건은 게임 코드와 별개이며 Play 검사는 완료됨. 해상도별 UI 및 장시간 수동 플레이는 미검증.

- 미사용 코드 정리 완료: 근접 AI·지형 마커·옛 출현 함수·미사용 분기·중복 외형 참조·미사용 피해 인자 삭제. 프리팹과 호출부 갱신. 전투/프리팹 검사, 별도 Unity 프로젝트 Play 검증, Windows64 빌드 통과. 검증 에디터 SearchDatabase 인덱스 예외는 이전과 동일하며 게임 Play 검사는 통과. 장시간 수동 플레이 미검증.

- 포획 시 찌 표시 어긋남 및 수리검의 일반 오브젝트 충돌 수정. 포획/해제 표시·줄 끝 좌표, 반사 전후 오브젝트 충돌 제외 회귀 검사 추가. 전투·프리팹 검사 및 Windows 빌드 통과.

- 시트 연결(2026-11-02): feature/spreadsheet-integration에서 플레이어·적 탭 CSV 다운로드 메뉴와 최초 CSV 추가. 비로그인 CSV 응답·헤더 확인 및 Unity 6000.3.11f1 참조 어셈블리 기반 C# 컴파일 통과. 게임 수치 적용은 범위 제외. Unity 메뉴 실행 검증은 대기.

- Integration 시트 테스트(2026-11-02): 연결 관련 스크립트를 Assets/Externals/Scripts 및 Editor 하위로 이동·추가하고 Integration.unity에 Enemy_TableDummy 배치. Play에서 실제 시트 연결 성공 및 플레이어·적 전체 스탯 로그 확인. 적 hp=60 초기화, Input System F키 이벤트로 60→50→…→0, 키 유지 시 반복 차감 없음, 0 하한, 실제 프레임 진행 검사 통과. 원본 시트 쓰기 및 기존 전투 씬 변경 없음.

- SO·Play 자동 갱신(2026-11-02): 플레이어·적 시트의 모든 행을 Assets/Externals/Data/Stats의 CombatStatDefinition SO로 가져오고, Assets/Externals/Scenes/Integration.unity의 적에 SO 할당 완료. Play 시작 및 완료 후 5초마다 시트 조회, 변경된 값만 영구 SO 에셋에 저장·적에 반영. 최대 체력 갱신은 기존 피해량을 보존하며 F키 피해는 인스턴스에서만 관리. 실제 원본 자동 조회 2회, 로컬 CSV 변경 입력에 대한 SO 갱신/참조 GUID 유지/60→80 최대 체력 변경 시 피해 10 보존(70/80), 변경 없음 건너뛰기, 잘못된 값 거부, F키·체력 0 하한 검사 통과. 테스트 데이터는 로컬에서 원래 SO 값으로 복구했으며 원본 시트 쓰기 없음. ## 플레이어 기획 갱신 (2026-11-07)

- feature/player: 0.5초 직선 공격(전체 폭 attackWidth, 적당 1회 attack 피해), 원형 타겟팅·0.3+catchHold 포획, 거리 catchRange/2 유지, E 내려찍기(120%/110%), Q 부채꼴 보정 투척 구현.
- 수리검 flySpeed*2·attack*1.5, 포획 중 물리 충돌 피해 중복 방지, 사망 해제, 오브젝트 비파괴 유지. 저장 키 F로 이동하고 CSV 안내 갱신.
- 기존 SO에 attackWidth/catchRange/catchHold 선택 열 파싱 추가. 원본 시트 쓰기 없음. 기본값 폭 0.6/포획 거리 7.5/추가 홀드 0. 일반/무거운 적은 현재 같은 사천당가 SO를 참조하며 종류별 SO 연결 가능.
- 검증: 별도 Unity 6000.3.11f1에서 기본공격 유지·중복 방지, 타겟 우선순위·범위, 추가 홀드·취소, 포획 거리, 바닥/적/오브젝트 내려찍기·사망 해제, 투척 각도·동각 거리, 시트 이전/확장 헤더 검사 통과. 입력 주입 Play에서 좌클릭·E·Q·수리검 속도/명중 피해 확인. Windows64 빌드 통과. 검증 에디터의 기존 SearchDatabase 예외는 게임 로직 밖에서 발생.
- 미검증: 장시간 직접 조작감, 원본 시트 새 열 실제 편집. 수치/연출 속도 미정 항목은 Inspector 기본값으로 적용. 회피/스킬 추가 없음.

- 사용자 피드백 반영: 새 기획 적용 과정에서 잃었던 PoC의 곡선 전개/낚싯줄 처짐/포획 관성 복원. 강제 위치 이동·Kinematic 포획 제거, 힘과 장력으로 거리 조정 및 E 내려찍기. E 피해는 실제 충돌 시 1회, 일반 Q는 운동 속도 유지(기본 속도 하한), 수리검 규칙 유지. 자동 회귀·입력 Play·화면 렌더·Windows 빌드 통과. 로컬 시트 자동 갱신 SO 변경/신규 적 SO는 이번 수정 커밋에서 제외하고 보존.

- 클릭 시 직선 가이드 표시 제거. 곡선 낚싯줄과 공격 판정은 유지. 표시 활성화 코드 제거 및 diff 검사 완료.
