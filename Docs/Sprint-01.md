# 스프린트 01 — 협업 규칙 적용

기간: 2026-10-30 ~ 2026-11-05 (1주 초안).
목표: 기존 전투를 유지하면서 협업 규칙을 적용하고 다른 담당자가 텍스트와 코드를 찾을 수 있게 한다.
담당자·리뷰어와 실제 일정은 팀에서 배정한다. 이 문서는 완료된 스프린트 이력이 아니다.

| 작업 | 상태 | 완료 기준 |
| --- | --- | --- |
| feature 브랜치 및 Git 연결 | 로컬 완료 | 원격 기존 이력을 유지하고 feature/team-conventions에서 작업 |
| 필드명·오브젝트 이름 정리 | 구현 완료 | camelCase, 직렬화 이전 이름 보존, 표시 이름 분리 |
| 표시 텍스트 CSV | 구현 완료 | 키 조회, 번역 대체, 잘못된 CSV 검증 |
| 문서·PR 템플릿·로컬 훅 | 구현 완료 | 커밋 헤더 및 보호 브랜치 푸시 검사 |
| 자동 검사 | 통과 | 전투·CSV·훅 검사 통과 |
| 실제 전투 플레이 | 미완료 | 공격·포획·투척·보정·독가스·저장 확인 |
| 원격 develop 초기 생성·보호 규칙 | 관리자 작업 필요 | PR 필수·승인 1명·직접 푸시 차단 |
| PR 리뷰·병합 | 미진행 | 최소 1명 승인 후 develop에 PR 병합 |

범위 제외: 밸런스 SO/스프레드시트 연결, 기본 PoC 수정, Linebreaker 수정, 새 전투 규칙.

검증 기록: 전투·CSV 회귀 검사, 로컬 훅 차단 검사, 씬 초기화 검사 통과. 기본 PoC/Linebreaker/전투 씬 원본 해시 유지. 검증용 Unity의 검색 인덱스 내부 예외 1건은 게임 코드 밖에서 발생했으며 플레이 초기화 검사는 통과했다. 실제 UI 배치·조작감 검증은 미완료.

후속 작업(2026-10-31): 플레이어·낚싯대 프리팹 전환 및 씬 배치 완료. 전투 회귀·프리팹 참조·에디터 수정값 유지·Play 모드 공격 시작 검사 통과. 적·맵·HUD의 에디터 전환은 다음 단계.

전체 전환(2026-10-31): 적·수리검·독·병·돌·맵·문·위치 마커·카메라·진행 시스템·Canvas HUD·줄/찌/조준선·효과음을 프리팹/에셋으로 이관. RuntimeInitialize/OnGUI/게임 실행 중 컴포넌트 조립 제거. 전투 중 생성은 프리팹 Instantiate만 사용. 기존 팀 리뷰·원격 병합 상태는 변경하지 않음.

- 전체 프리팹 전환 최종 검증: 별도 Unity 6000.3.11f1 검증 프로젝트에서 전투 회귀·프리팹 검사, 실제 Play(적 출현·수리검·병 소모와 보라색 독 피해·플레이어 중독), Windows64 빌드 통과. 씬/프리팹 에셋 GUID 누락 없음. 검증 에디터의 SearchDatabase 인덱스 예외 1건은 게임 코드와 별개이며 Play 검사는 완료됨. 해상도별 UI 및 장시간 수동 플레이는 미검증.

- 미사용 코드 정리 완료: 근접 AI·지형 마커·옛 출현 함수·미사용 분기·중복 외형 참조·미사용 피해 인자 삭제. 프리팹과 호출부 갱신. 전투/프리팹 검사, 별도 Unity 프로젝트 Play 검증, Windows64 빌드 통과. 검증 에디터 SearchDatabase 인덱스 예외는 이전과 동일하며 게임 Play 검사는 통과. 장시간 수동 플레이 미검증.
